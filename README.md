# Personalized-Healthcare-Recommendation-System
Healthcare data analysis using Python, MySQL, and Power BI with rule-based sleep analysis.
# Personalized Healthcare Recommendation System

## About the Project

I developed this project to explore healthcare and lifestyle data using Python, MySQL, and Power BI. The main goal was to understand patterns in sleep duration and other health indicators, organize the data, and turn it into meaningful insights through data analysis and visualization.

## Tools and Technologies

I used Python and the Pandas library to clean and prepare the dataset and categorize sleep duration based on a selected target range. MySQL was used to store the processed data and write queries for analyzing the results. I also used Power BI to create interactive dashboards that make the findings easier to understand.

## What I Worked On

Throughout this project, I worked on preparing the dataset, handling data inconsistencies, and organizing the information for analysis. I used Python to categorize sleep duration and SQL queries to summarize the results. I then explored the findings in Power BI to present the data through charts, comparisons, and key indicators.

## Key Findings

In the analyzed dataset of 374 records, 219 records (58.56%) fell within the selected sleep-duration target of 7–9 hours, while 155 records (41.44%) were below that target. No records were above the selected range. These results describe the dataset and are intended for educational analysis, not medical diagnosis.

## Project Structure

The project is organized into separate folders for Python notebooks, SQL scripts, data files, Power BI reports, and analysis results. This structure helps keep the code, data, and reporting work organized and makes the project easier to follow.

## What I Learned

While working on this project, I gained practical experience in data cleaning with Python, writing SQL queries, organizing data for analysis, and presenting findings through Power BI. It also helped me understand how these tools can work together in a complete data analytics workflow.

## Project Goal

This project is part of my learning journey in data analytics. I wanted to apply my knowledge of Python, SQL, and Power BI to a practical dataset and build a project that demonstrates my skills in data preparation, analysis, and visualization.

**Note:** The sleep-duration categories used in this project are for educational analysis only and should not be treated as medical advice.
